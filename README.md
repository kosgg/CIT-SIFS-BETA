# SIFS 로컬 베타

SIFS 화면 시안을 바탕으로 만든, 브라우저에서 실행하는 단일 기기 베타입니다. 별도 패키지 설치나 서버 설정 없이 `index.html`을 Chrome 또는 Edge에서 열어 사용할 수 있습니다.

## 포함 기능

- 제목·본문 키워드 검색, 분류 필터, 최신순 정렬
- 게시글 상세 보기와 원문 링크
- 게시글 직접 등록, 수행 과목·마감일 지정, 이미지 첨부
- 학생 프로필, 과목별 요일·교시 시간표 저장 및 수정·삭제
- 선택 과목에 연결된 다가오는 수행평가 표시
- 게시글 JSON 가져오기와 백업 내보내기

## 베타 범위

- 게시글, 프로필, 시간표는 현재 브라우저의 `localStorage`에 저장됩니다. 다른 기기나 브라우저와 동기화되지 않습니다.
- Google OAuth 대신 이 기기에서 이름·학급을 설정하는 로컬 프로필을 사용합니다.
- 학교 공지는 예시 데이터로 표시합니다. 학교 사이트에서 자동으로 수집하지 않습니다. JSON 가져오기를 이용해 게시글 데이터를 불러올 수 있습니다.
- 실제 학교 사용을 위한 계정 인증, 서버 DB, 자동 수집 예약은 네트워크·서버·인증 설정이 준비된 다음 단계 기능입니다.

## 데이터 백업

통합 검색 화면 오른쪽의 **백업 내보내기**로 게시글 JSON을 저장할 수 있습니다. 같은 영역의 **JSON 가져오기**로 `posts` 배열을 포함한 JSON 파일을 불러옵니다.

시간표와 프로필도 브라우저 저장소에 보관됩니다. 이 베타를 초기화하거나 브라우저 데이터를 지우면 저장한 정보가 사라질 수 있으니 게시글을 정기적으로 내보내 보관하세요.

## 화면 확인 목록

1. 통합 검색: 검색·분류 필터·최신순·결과 없음 상태를 확인합니다.
2. 나의 학교생활: 과목을 추가하고 시간표 칸을 눌러 수정·삭제합니다.
3. 정보 등록: 필수값을 비워 제출했을 때 안내를 확인한 뒤 게시글과 이미지를 등록합니다.
4. 게시글 상세: 검색 목록에서 게시글을 열고 마감일·출처·관련 정보를 확인합니다.
5. JSON 백업: 내보낸 파일을 다시 가져와 게시글이 반영되는지 확인합니다.

## 프로젝트 규칙 적용

- JavaScript 함수와 데이터 처리 함수 이름은 영어로 작성합니다.
- API 키나 비밀값을 저장하지 않습니다.
- 외부 라이브러리를 추가하지 않고 HTML, CSS, JavaScript 표준 기능을 사용합니다.
- 화면이나 동작을 바꾼 뒤에는 위 화면 확인 목록으로 브라우저에서 확인합니다.
